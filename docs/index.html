About

Jaguares Social Automation is a private software application developed exclusively to manage the official social media accounts of Jaguares MTB Yucatán.

The application automates Facebook publications, ride announcements, birthday greetings, photo albums and approval workflows through Telegram before content is published.

This application is intended exclusively for authorized administrators of Jaguares MTB Yucatán. It is not offered as a public or commercial service.
